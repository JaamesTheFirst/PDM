# 🚲 EcoTransit — Sustainable Transport App

**EcoTransit** is a cross-platform mobile application that helps users find and plan eco-friendly travel routes using sustainable transportation grids (e.g. e-bikes, electric buses, solar charging stations, etc.).

Inspired by apps like **Moovit**, but focused on **green energy and sustainability**, this app is designed to promote smart, low-emission mobility.

---

## 🌍 Features (Planned)

- 📍 Map-based route planning
- 🚌 Real-time transit info (bike lanes, electric buses, etc.)
- ⚡ Charging stations locator
- ♻️ CO₂ savings estimation per trip
- 🧭 Navigation & ETA
- 🗺️ Multi-city support (maybe)
