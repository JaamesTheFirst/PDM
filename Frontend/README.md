# EcoMove - Sustainable Transport App

Flutter mobile application for finding eco-friendly transportation routes.

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   flutter pub get
   ```

2. **Set up Mapbox (required):**
   See [SETUP_MAPBOX.md](SETUP_MAPBOX.md) for instructions on getting your Mapbox access token.

3. **Run the app:**
   ```bash
   flutter run
   ```

## 📋 Prerequisites

- Flutter SDK
- Dart
- Android Studio / Xcode (for mobile development)
- Mapbox account (free tier available)

## 🗺️ Mapbox Setup

Each developer needs to add their Mapbox token to:
- `android/app/src/main/AndroidManifest.xml` (line 4)
- `ios/Runner/Info.plist` (line 3)

See [SETUP_MAPBOX.md](SETUP_MAPBOX.md) for detailed instructions.
